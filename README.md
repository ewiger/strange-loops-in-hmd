# strange-loops-in-hmd

There are several reasons for this project to exists:

1. Anticipate a practical answer to `What is an AI-oriented Programming Language?` or even define one.
2. Define what `strange loop` means following on the works by Douglas Hofstadter ([Gödel, Escher, Bach](https://en.wikipedia.org/wiki/G%C3%B6del,_Escher,_Bach) and [I Am a Strange Loop](https://en.wikipedia.org/wiki/I_Am_a_Strange_Loop)) and what does it mean for modern AI work.
3. Attempt to build such a loop using [HyperMarkDown](https://hypermarkdown.org) (HMD) cards that can be dynamically executed with human feedback.
4. Design and test AI support in [Hyper Query Language](https://hql-lang.org) (HQL), which is used inside HMD cards.
5. Learn as much as possible in the process next to the newly developed dynamic formalism to interact with AI Agents.

There well may be other goals to achieve but it is enough to get the idea of what this repository contains.
